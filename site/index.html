ZIKAR

zikar.cl ↗

SaaS multitenant B2B de gestión de flotas para empresas con varias sucursales.

Por qué

Las empresas de transporte, construcción y minería suelen llevar su flota en planillas distintas por sucursal: documentos que vencen sin aviso, traslados de vehículos sin registro y ninguna trazabilidad de quién condujo qué. ZIKAR centraliza vehículos, conductores, documentos y contratos en una sola plataforma, con workflows de aprobación y auditoría.

Arquitectura y soluciones técnicas

  • Multitenancy con Row Level Security: aislamiento de datos por tenant (company_id) a nivel de base con políticas RLS en Postgres. RBAC con cuatro roles; el backend resuelve el rol desde la base y no confía en los claims del JWT.
  • Workflow de aprobaciones: la sucursal solicita traslados o bajas, la empresa aprueba, y cada evento queda en un audit log, incluida la impersonación de soporte vía magic link.
  • QR por vehículo: token aleatorio y rotable; el conductor lo escanea para registrar el trabajo diario contra un contrato, validado con funciones RPC en Postgres. Sticker y credencial se exportan a PDF en el cliente.
  • Billing recurrente con Transbank Oneclick: tokenización de la tarjeta y un job de pg_cron que llama a un endpoint protegido por secreto para hacer cobros idempotentes.
  • CI/CD de base de datos: 66 migraciones SQL versionadas que GitHub Actions aplica con supabase db push en cada push a main, más un webhook de GitHub firmado con HMAC que publica el changelog.

LUKY Propiedades

luky.cl ↗

Portal inmobiliario map-first para venta y arriendo en Chile, web y app móvil.

Por qué

Buscar casa en Chile significa recorrer comunas a ciegas, llamar por precios que no están publicados y conocer el barrio recién después de firmar. LUKY pone todo el mercado sobre un mapa, con precios por zona, contacto directo con quien publica y sin comisión.

Arquitectura y soluciones técnicas

  • Geoprocesamiento "Zona Luky": al geolocalizar una propiedad, el servidor consulta matrices e isócronas a pie de OpenRouteService contra puntos de interés de OpenStreetMap ingeridos en la base, y calcula un score de caminabilidad.
  • Mapa de precios: agregación en grilla hexagonal y clasificación de cada celda (económica, media o premium) por terciles calculados sobre datos reales. Render con MapLibre GL y clustering con supercluster.
  • API de publicación segura: verificación de JWT y membresía en la organización, validación de schema con zod, cuotas por plan y requests idempotentes. El service role solo se usa en el servidor.
  • Matching en la base: funciones SQL y triggers que puntúan las búsquedas guardadas contra el inventario para generar recomendaciones.
  • Pipeline de deploy: GitHub Actions despliega a Cloudflare Workers solo si las migraciones de producción pasan, con preview deployments por PR y CI de base de datos.
